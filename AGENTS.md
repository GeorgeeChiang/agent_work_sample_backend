# Agent Instructions

- This repo is the backend service for the library sample system.
- Keep API responses source-code free when used by the agent workflow demo.
- Prefer small, explicit FastAPI endpoints and SQLAlchemy models.
- Database state must be persisted through PostgreSQL in Docker Compose.
- Seed data should preserve the demo scenario: 10 books, users user1/user2/user3, and user1 has borrowed one book.
